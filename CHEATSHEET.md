# 📝 Cheat Sheet

Quick answers for when you're filling in your README.

## ✏️ Writing links (the "no spaces" rule)

Links can't contain normal spaces or some symbols. Swap them like this:

| Character | In the banner | In the typing lines |
|---|---|---|
| space | `%20` | `+` |
| `@` | `%40` | `%40` |
| `&` | `%26` | `%26` |
| `#` | `%23` | `%23` |
| new line | — | `;` |

Example: **"CS @ NYU"** → banner `CS%20%40%20NYU`, typing `CS+%40+NYU`

## 🔤 Markdown basics

| You type | You get |
|---|---|
| `### Title` | a heading |
| `**bold**` | **bold** |
| `*italic*` | *italic* |
| `- item` | • a bullet point |
| `[text](https://link.com)` | [a clickable link](https://github.com) |
| `` `code` `` | `code` |
| a blank line | a new paragraph |

## 🎨 Banner settings

Edit these parts of the banner link:

| Setting | What it does | Try |
|---|---|---|
| `type=` | Banner shape | `waving`, `wave`, `rect`, `slice`, `egg`, `shark` |
| `color=` | Gradient colors | `0:03045E,100:00B4D8` (start → end) |
| `height=` | How tall | `120` to `220` |
| `fontSize=` | Name size | `36` to `60` |
